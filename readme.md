# ROUTER 448461

Personal digital asset referral directory maintained by Joshua Esk.

## Purpose

A transparent directory for selected exchange referral links, referral codes and QR access. Referral relationships are disclosed openly, and official platform destinations are provided separately.

## Current system

- ROUTER 448461 public directory
- Desktop and mobile interface
- First-party QR assets
- Cloudflare Pages production deployment
- GitHub-hosted source on branch `router448461.com`
- Strict HTTP security headers and CSP
- Automated GitHub Actions integrity, hygiene and security validation

## Security model

The production site is intentionally static and first-party. It does not use a service worker, plugins, embedded frames or inline JavaScript/CSS.

Security controls include HSTS, CSP, clickjacking protection, MIME-sniffing protection, restrictive Permissions Policy, COOP/CORP, strict referrer handling and immutable caching for static assets.
